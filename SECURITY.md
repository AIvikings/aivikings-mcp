# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues or discussions.

Email **support@aivikings.ai** with "Security" in the subject line. Include:

- what you found and where (this repository, the hosted MCP server at `mcp.aivikings.ai`, or the AiVikings.ai API)
- steps to reproduce
- the impact you think it has

We will confirm receipt within 3 business days and keep you updated until it is resolved. Please give us reasonable time to fix the problem before you disclose it publicly.

## Supported versions

We support the latest version on the `main` branch and the hosted server at `https://mcp.aivikings.ai/mcp`.
